# Seed Plan

Initial seed order:

1. Approve source registry entries.
2. Add a small set of well-known public universities.
3. Review IDs, aliases, websites, and location fields.
4. Build fixture and release artifacts.
5. Expand coverage in source-backed batches.

The [2026–2027 admissions review](post-seed/ADMISSIONS_2026_2027_REVIEW.md)
starts program work with university identity matching. It adds aliases to
existing IDs without expanding the production scope. The subsequent
[program pilot](post-seed/PROGRAM_PILOT_2026_2027.md) adds the first offerings
within those existing identities and introduces a shared discipline ID.
The [first public batch](post-seed/BULK_NAMED_PROGRAMS_2026_2027.md#thirteenth-local-batch)
adds verified offerings from announcement 6 to four existing university profiles.
The [city-grouped public review](post-seed/PUBLIC_CITY_PROGRAMS_2026_2027.md)
uses announcement 2 to extend the existing profiles with verified awards.

## v0.1.0 Status

The first seed release includes 57 university and higher-institute records.
This remains the production canonical boundary until additional records are
confirmed in the approved production scope or OpenSyria approves a broader
scope rule.

Post-seed expansion is tracked in [Post-Seed Backlog](POST_SEED_BACKLOG.md).
