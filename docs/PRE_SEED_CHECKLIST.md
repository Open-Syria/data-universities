# Pre-Seed Checklist

The [2026–2027 admissions review](post-seed/ADMISSIONS_2026_2027_REVIEW.md)
records the approved alias batch. The [program pilot](post-seed/PROGRAM_PILOT_2026_2027.md)
shows the review required for canonical offerings. Verify the campus,
faculty parent, discipline, and route year against the cited sources.
Use the [city-grouped public review](post-seed/PUBLIC_CITY_PROGRAMS_2026_2027.md)
to check affiliation evidence when the Ministry table gives only a city.
For public programmes, check the award and institution for the specific
campus in [the announcement 6 review](post-seed/BULK_NAMED_PROGRAMS_2026_2027.md#thirteenth-local-batch).

Before adding real records:

- confirm the source license is reusable,
- add the source to `data/sources.json`,
- create an import manifest,
- add only public institution facts,
- avoid private personal data,
- run `pnpm run validate`.
