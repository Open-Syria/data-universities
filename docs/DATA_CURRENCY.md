# Data Currency

University data changes over time. Prefer sources with clear publication or access dates, record import manifests for every batch, and keep `sourceReferences[].accessedAt` current when source-backed records are reviewed or refreshed.

Fields most likely to change:

- operating status,
- official website,
- public address,
- institution naming.

Cover photos can be older than the record they illustrate. Asset
`sourceReferences[].sourceRecordDate` keeps the date recorded for each Commons
file; for example, the Latakia University cover was photographed in 2002, when
the institution was Tishreen University. Replace a cover when a newer
free-licence photo passes review.
